# 求职者页面UI优化计划

## 📋 项目概述

基于 **frontend-design** 和 **ui-ux-pro-max** 技能指导，对智能招聘系统求职者端页面进行全面UI优化，打造现代、专业、吸引人的求职体验。

## 🎯 设计方向

### 设计风格
- **风格定位**: Modern Professional + Content-First
- **核心特点**: 清晰的信息层次、流畅的交互体验、专业的视觉呈现
- **差异化**: 突出职位信息展示效率，强化求职者信任感

### 色彩系统
```
主色调: #4F46E5 → #6366F1 (深蓝紫渐变)
强调色: #F97316 (活力橙 - 用于薪资和CTA)
成功色: #22C55E (录用状态)
警告色: #EAB308 (待处理状态)
中性色: Gray Scale (文字和背景层次)
```

### 字体系统
```
标题: Inter (600-700 weight)
正文: Inter (400-500 weight)
数字: Tabular Figures (薪资、统计)
```

## 🛠 技术实现要点

### 动画规范
```scss
// 进入动画
@keyframes slideUp {
  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }
}

// 卡片悬浮
.hover-lift {
  transition: transform 200ms ease, box-shadow 200ms ease;
  &:hover {
    transform: translateY(-4px);
    box-shadow: var(--shadow-xl);
  }
}

// 渐变背景
.gradient-hero {
  background: linear-gradient(135deg, #4F46E5 0%, #6366F1 50%, #818CF8 100%);
}
```

### 响应式断点
```scss
$breakpoints: (
  'mobile': 375px,
  'tablet': 768px,
  'desktop': 1024px,
  'wide': 1440px
);
```

### 组件复用
- JobCard: 职位卡片组件（首页、收藏、搜索结果复用）
- CompanyCard: 企业卡片组件
- StatCard: 统计数据卡片组件
- StatusBadge: 状态徽章组件

## ✅ 验收标准

### 视觉质量
- [ ] 所有页面风格统一
- [ ] 色彩对比度符合WCAG AA标准
- [ ] 字体层级清晰
- [ ] 间距符合8dp原则

### 交互体验
- [ ] 所有可点击元素有hover效果
- [ ] 页面切换有过渡动画
- [ ] 加载状态有骨架屏
- [ ] 错误状态有友好提示

### 响应式
- [ ] 移动端（375px）正常显示
- [ ] 平板端（768px）正常显示
- [ ] 桌面端（1440px）正常显示

### 性能
- [ ] 首屏加载 < 2s
- [ ] 动画帧率 ≥ 60fps
- [ ] 无布局抖动（CLS < 0.1）

---

## 📌 注意事项

1. **保持现有功能不变**：仅优化UI，不改变业务逻辑
2. **渐进式优化**：优先完成首页，再逐步优化其他页面
3. **组件复用**：提取公共组件，避免重复代码
4. **性能优先**：避免过度动画，保持页面流畅
5. **无障碍支持**：确保键盘导航和屏幕阅读器支持
